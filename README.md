# gamification-achievements-system
Gamification Achievements System for a Learning Portal using Django, Django REST Framework and React, with points, badges and leaderboard for learner engagement

## Problem Statement
Short summary of the engagement problem in online learning portals.

## Objectives
- Implement points, badges, and leaderboard to motivate learners.
- Provide REST APIs and a React dashboard for progress tracking.

## Tech Stack
- Django, Django REST Framework
- React, React Router, Axios
- PostgreSQL or SQLite

## Features
- Points system for quiz and course events
- Badge unlocks for milestones
- Leaderboard ranking for users
